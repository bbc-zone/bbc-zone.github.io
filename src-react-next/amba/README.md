# Mie Ayam Bakso Amba React Landing Page

React/Vite landing page based on the requested React reference structure. It includes a home page, searchable menu, item details, local cart, GoFood handoff, and information pages.

Menu names and starting prices in `src/data/products.js` are provisional because the linked GoFood page could not be read during implementation. Confirm and update them against the live menu. Store details and FAQ copy live in `src/data/site.js`. Ordering and payment are completed on GoFood.

Run `npm install`, then `npm run dev`. `npm run build` writes the static site to `dist/`.
